# HS Reconnect 2.0.0

HS Reconnect now combines a Battlegrounds reconnect shortcut with a local Solo
lobby overlay in a redesigned Mac app.

- Reconnect with Command-Shift-W, or change the shortcut in the app.
- See player names, public leaderboard ranks and ratings, and an estimated Solo
  lobby average. Move and resize the overlay with Command-Shift-L.
- Set up the reconnect extension from the app. When approval is needed, the app
  opens Network Extension Settings and shows the next step. macOS still shows
  its own extension and proxy approval prompts.
- Receive signed in-app updates, with automatic checks and a manual check in
  Settings. Updates use the app ZIP; new installations use the DMG installer.
- Report a bug in the app with an optional reply email and up to five images.
- Count app sessions and feature use through TelemetryDeck. Captured lobby data
  and game traffic stay local; see the repository's privacy statement.
- Uninstall from Settings when you want to remove the app and its local setup.

Requires macOS 13 or later and the native macOS version of Hearthstone. Supports
Apple silicon and Intel Macs. Lobby info is for Solo Battlegrounds; quit
HSTracker before using the lobby overlay.

To upgrade an existing installation, run the new installer over the old app.
Your shortcut and preferences remain. The app is unofficial and is not
affiliated with Blizzard Entertainment.
