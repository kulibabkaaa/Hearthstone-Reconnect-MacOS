# HS Reconnect 2.2.1

Reconnect is more reliable, and lobby info now runs on HS Reconnect's own code.

**Added**

- Bug reports can include logs, with personal details removed. You can check them before sending, or turn them off.
- A spinner while a bug report is sending.

**Changed**

- The Reconnect button no longer needs any permission.
- Lobby info now runs on HS Reconnect's own code. It still asks for Developer Tools access.
- Uses about half as much CPU.
- Recognises more Battlegrounds modes, including future ones.

**Fixed**

- Reconnect no longer says "No game found" after some matches.
- The lobby overlay no longer blinks during a reconnect.
- Bug reports show the right Battle.net region.

Requires macOS 13 or later and the native macOS version of Hearthstone. Supports Apple silicon and Intel Macs. Version 2.0.0 and later can install this update from the app. For earlier versions, run the new installer over the old app. The app is unofficial and is not affiliated with Blizzard Entertainment.
